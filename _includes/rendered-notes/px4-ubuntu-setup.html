什么是PX4

PX4 是一款专业级飞控。 它由来自业界和学术界的世界级开发商开发，并得到活跃的全球社区的支持，为从竞速和物流无人机到地面车辆和潜水艇的各种载具提供动力。

架构介绍

  • PX4架构使用UORB总线进行内部的通信。

  • 使用MAVLink与QGC地面站进行通信。

  • 使用uXRCE-DDS通过桥接内部的话题与ROS2通信。

  • 相关笔记： 2. 桥接器 uXRCE-DDS中间件

1.克隆PX4源码

git clone https://github.com/PX4/PX4-Autopilot.git --recursive

`
INFO
源代码中的环境配置脚本通常适用于最新的 PX4 版本。如果你使用的是较旧版本的 PX4，那么可能需要获取针对特定版本的源代码。

在 bash shell 中，无需提供任何参数即可运行 ubuntu.sh 脚本，以完成所有安装操作：

bash ./PX4-Autopilot/Tools/setup/ubuntu.sh
  • 在安装过程中确认并通过所有的提示。
  • You can use the --no-nuttx and --no-sim-tools options to omit the NuttX and/or simulation tools.
    你可以使用 --no-nuttx 和 --no-sim-tools 选项来跳过 NuttX 和/或仿真工具的使用。

2.下载 QGroundControl

官方推荐使用 AppImage：

  • GitHub Releases：
    https://github.com/mavlink/qgroundcontrol/releases
  • 下载文件名通常为：
    QGroundControl-x86_64.AppImage 或 QGroundControl.AppImage
    请选择与你版本适配的版本
