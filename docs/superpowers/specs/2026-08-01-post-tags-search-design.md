# Post Tags Filtering & Title Search

**Date:** 2026-08-01  
**Status:** approved

## Overview

Add tag-based filtering and title search to the Posts page (`/posts/`), keeping the existing year-based grouping.

## Layout

Two new UI areas at the top of `/posts/`, above the article list:

```
┌────────────────────────────────────────────────┐
│  🔍 [search input — filters by title]           │
├────────────────────────────────────────────────┤
│  [All(N)] [tag1(N)] [tag2(N)] ...              │
├────────────────────────────────────────────────┤
│  2026                                           │
│    📄 Post Title One                  tag1 tag2 │
│    📄 Post Title Two                  tag2      │
│  ...                                            │
└────────────────────────────────────────────────┘
```

- **Search bar**: text input, placeholder "Search post titles..."
- **Tag bar**: row of clickable pills/badges showing tag name + count. "All" is always first and is the default active state.

## Interaction

| State | Behavior |
|-------|----------|
| Default (search empty, "All" active) | All posts shown, grouped by year |
| Click a tag | Show only posts with that tag. Years with zero matching posts are hidden. "All" deselects, clicked tag highlights. |
| Type in search | Real-time filter posts whose title contains the keyword (case-insensitive). Hidden posts and empty year headers collapse. |
| Tag + search together | AND logic — post must match BOTH the selected tag and the search keyword |
| Click "All" | Reset tag filter, show all posts (search term remains) |
| URL hash | `/posts/#tutorials` activates that tag on page load |

## Implementation Plan

### Files to modify

1. **`_pages/year-archive.html`** → Add search input + tag bar HTML, Liquid loop to collect tags
2. **New: `assets/js/post-filter.js`** → Client-side filter logic (tag click, search input, URL hash, DOM show/hide)
3. **`_sass/layout/_page.scss`** or new partial → Tag pill styles, search input styles
4. **`_includes/scripts.html`** → Include the new JS file (non-module script tag)
5. **`assets/js/main.min.js`** → Not affected (filters are independent JS)

### Tag Data

Generated by Liquid at build time from `site.posts`:

```liquid
{% assign all_tags = site.posts | map: "tags" | compact | uniq | sort %}
```

Each tag pill is an `<a>` or `<button>` with `data-tag="tag-name"` and count from `site.posts | where_exp: "item", "item.tags contains tag" | size`.

### Filter JavaScript

- Attach `click` handler to tag buttons: add/remove `.hidden` class on `.archive__item` and `h2.archive__subtitle` (year headers)
- Attach `input` handler to search box: same logic, checking `textContent.toLowerCase().includes(keyword)`
- On page load, check `window.location.hash` for initial tag activation
- Pure vanilla JS or jQuery (site already has jQuery)

### Styling

- Tag pills: inline-block, rounded, subtle background, active state with accent color
- Search input: full width, rounded, subtle border, small icon on left
- Both themed with existing CSS variables for light mode compatibility

## Constraints

- No external libraries beyond existing jQuery
- Must work on GitHub Pages (static site, no build plugins beyond whitelist)
- Light mode only (dark mode toggle already removed)
- Mobile responsive: pills wrap, search full width
