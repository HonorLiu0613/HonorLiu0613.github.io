An IoT dashboard that visualizes sensor data in real-time. Built with a lightweight tech stack suitable for embedded systems.

## Features

- Real-time data visualization
- Multiple sensor support
- Alert and notification system

## Tech Stack

- Vue.js + ECharts
- Node.js backend
- MQTT protocol
- ESP32 sensors
