这个个人网站是基于 **Minimal Mistakes / AcademicPages** 主题搭建的，
托管在 GitHub Pages，支持 Markdown 写作、Collections 管理和响应式布局。

## 技术栈

- Jekyll 静态站点生成
- SCSS 样式定制
- jQuery 交互增强
- GitHub Pages 免费部署

## 主要功能

- 博客文章（Posts）— 支持标签分类和标题搜索
- 项目作品（Works）— 网格卡片展示
- 竞赛经历（Experience）— 时间线整理
- 在线简历（CV）
